# AI 圖片放大王 / AI Upscale King 1.0.0

首個開源正式版本：在自己電腦把 AI 圖片等比例放大至印刷尺寸。
First open-source release: proportional print-size upscaling on your own computer.

- Windows 10/11 x64 攜帶版（CPU；毋須 CUDA）。
- macOS 14+ Apple Silicon App（可用時使用 Apple GPU）。
- A1–A5、手動厘米尺寸，預設 300 DPI。
- 保留原圖比例及方向；A1 banner 不會變成直向紙張。
- 本機 Real-ESRGAN 圖片／插畫模型，文字／Logo 保真縮放。
- PNG／TIFF／JPEG，透明度、sRGB ICC 及解析度資訊。
- 簡潔介面、批次、局部比較、取消及錯誤提示。
- Apache-2.0 應用程式碼，中英文介紹及繁體中文教學。

下載對應 ZIP，完整解壓。Mac 把 App 放到本機應用程式資料夾；Windows 開啟 AIUpscaleKing.exe 並保留 _internal。模型已附帶，執行時毋須網絡。使用教學見倉庫 docs/使用教學.md。

Packages include model weights for offline runtime use. Extract the complete archive. See README.en.md for instructions. Source code archives require the build-time model download step.

SHA-256 files and native build verification reports accompany the packages. macOS is ad-hoc signed, not Developer ID notarized; Windows is not code signed. Follow normal system approval flows. These are 8-bit sRGB exports, not CMYK. Pixel/DPI targets do not certify print detail; inspect faces, text and artwork and make a print proof.
