# Changelog

## 1.0.0 — 2026-10-04

First open-source release line of AI Upscale King / AI 圖片放大王.

- Native Windows x64 CPU and macOS Apple Silicon build targets.
- A1–A5 sizing that follows the source aspect ratio and orientation.
- Custom centimetre dimensions on the main screen, default 300 DPI.
- Bundled offline Real-ESRGAN photo/anime models, faithful text/logo scaling.
- PNG/TIFF/JPEG, transparency, ICC conversion, print resolution metadata.
- Simplified interface, batch exports, local comparisons and cancellation.
- Apache-2.0 application license, English/Traditional Chinese documentation.
- Automated native tests, packaged executable checks and GitHub release pipeline.
