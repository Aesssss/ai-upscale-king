# AI 圖片放大王使用教學

## 安裝

在 [GitHub Releases](https://github.com/Aesssss/ai-upscale-king/releases) 下載自己系統的 ZIP；不要把 GitHub 的「Source code」當作桌面程式。

**macOS**：適用於 Apple Silicon、macOS 14 或更新版本。解壓後把「AI 圖片放大王.app」放入本機應用程式資料夾，雙擊開啟。建議不要在雲端同步資料夾內執行未壓縮 App。App 採 ad-hoc 簽署，尚未作 Developer ID 公證；如被攔截，使用 macOS 的正常「私隱與保安」開啟流程。

**Windows**：適用於 Windows 10／11、64 位元。完整解壓 ZIP，保留 `AIUpscaleKing.exe` 與 `_internal` 資料夾的相對位置，再執行 EXE。這是攜帶版，毋須安裝 Python、CUDA 或模型。Windows 包沒有程式碼簽署，首次執行可能出現提示。請先確認下載來源及校驗值。

## 放大橫向 banner 至 A1

1. 拖入橫向圖片，或按「選擇圖片」。
2. 印刷尺寸選「A1」。預設為 300 DPI。
3. 查看尺寸列：以原圖比例顯示成品大小。例如 3:1 banner 為約 84.1 × 28.0 cm、9934 × 3311 px。
4. 按「放大至 A1」，選輸出檔名及位置。
5. 完成後按「查看檔案」，再用設計軟件檢查成品。

A1 是尺寸範圍，並不把所有來源變成直向紙張。原圖方向與比例會保留；長寬比例不同時，成品不會填滿整張 A1。

## 放大至 40 × 60 cm、300 DPI

1. 加入圖片。
2. 印刷尺寸選「自訂」。
3. 在兩個厘米欄輸入 `40` 和 `60`。300 DPI 已預設。
4. 核對下方實際尺寸，按「等比例放大」。

2:3 直向圖會輸出 4725 × 7087 px；3:2 橫向圖會輸出 7087 × 4725 px；3:1 banner 則為約 60 × 20 cm、7087 × 2362 px。保留全圖比例時，無法同時填滿不同的長寬比例。欄位是兩個邊長，不會要求把橫圖旋轉成直圖。

自訂邊長支援 0.1–199 cm、兩位小數。修改後畫面即時更新成品尺寸。整數像素取整會有極小的尺寸差異。

## 選擇模式與預覽

按「進階設定」：

| 模式 | 適合用途 |
|---|---|
| 一般圖片 | 照片及一般 AI 生成圖 |
| 動漫／插畫 | 插畫、線條及動漫風格 |
| 文字／Logo 保真縮放 | 保持原字形；使用 Lanczos，毋須 AI 重建 |
| 自然／標準 | 一次 AI 4×，再精確調整成品大小 |
| 加強／較慢 | 大倍率時再做一次 AI 重建；需檢查內容變化 |

雙擊圖片或按 `P` 比較局部；拖動比較線或按左右鍵調整。`Esc` 返回全圖。保真模式的比較會清楚標示保真縮放；AI 局部預覽顯示第一次 4×，加強模式的第二次結果需核對完整匯出。

需要完整紙張時，可在進階比例設定主動選「完整紙張 · 留白」或「完整紙張 · 置中裁切」。預設「等比例原圖」沒有加邊或裁切。尺寸方向設定改變範圍排列，不旋轉原圖。

## 批次、取消與快捷鍵

一次加入多張圖片，匯出時選資料夾。每張跟隨自己的方向及比例；損壞來源會顯示逐張錯誤。右上「⋯」管理清單；移出佇列不刪除來源檔案。

| 操作 | macOS | Windows |
|---|---|---|
| 加入圖片 | Command + O | Ctrl + O |
| 匯出 | Command + Shift + S | Ctrl + Shift + S |
| 進階設定 | Command + , | Ctrl + , |
| 比較局部 | P／雙擊圖片 | P／雙擊圖片 |
| 移出佇列 | Delete／Backspace | Delete／Backspace |

處理時可按取消。AI 完成目前區塊後停止；大型圖片編碼可能需要等待該步完成。原圖保留。

## 格式、色彩與印刷

輸入 PNG、JPEG、TIFF、WebP、BMP 單張圖片。輸出 PNG、TIFF 或 JPEG；PNG／TIFF 保留透明度，JPEG 使用白色背景。

處理及輸出為 8-bit sRGB；有效來源 ICC 會轉換至 sRGB。16-bit／浮點、多頁 TIFF／動畫，以及沒有 ICC 的 CMYK 來源會拒絕。若需 CMYK，請由設計軟件按印刷商指定 ICC 轉換。輸出內有解析度及 sRGB ICC，不保留來源 EXIF／GPS。

DPI 欄位表示每英寸像素數，檔案保存相應 PPI 資訊。僅修改 DPI 標籤並不增加像素；本工具會實際產生指定像素的放大圖。

請檢查面孔、文字、商標及紋理。AI 可產生新細節，也可改變原有圖案；A1 像素數並不是印刷品質認證。文字和商標適合原始向量，重要作品請先打樣。

## 私隱與常見問題

圖片在本機處理，軟件沒有上傳或帳號。兩款模型已附帶。選擇的資料夾若由 Dropbox／iCloud 同步，該服務仍可能同步檔案；敏感稿件請用未啟用同步的本機位置。

- **很慢**：Windows CPU、較大來源及加強模式較慢。先比較局部，或試標準模式。
- **尺寸超限**：本版實際成品上限 1.6 億像素；降低厘米或 DPI。
- **模型校驗失敗**：重新下載並完整解壓發佈包，不要只複製 EXE。
- **圖片無法讀取**：另存一張有有效 ICC 的 8-bit RGB 副本。
- **輸出大小與輸入厘米不同**：先核對比例；為保留原圖，成品按指定範圍等比例縮放。

提交問題時，附版本、作業系統、來源像素、設定及錯誤文字即可。請勿把保密設計稿放到公開 Issue。
